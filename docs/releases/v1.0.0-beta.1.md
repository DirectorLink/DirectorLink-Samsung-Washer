## DirectorLink · Samsung Washer 1.0.0-beta.1

**Beta.** First release. Follow a Samsung Wi-Fi washing machine in Control4: its state, programme, time left and
finish time on a **Washer** tile, events when a cycle starts, pauses and finishes, and safe Pause, Resume, Stop and Start.

Free, open-source Control4 driver for Samsung Wi-Fi washing machines, through the Samsung SmartThings cloud.
Part of [DirectorLink Drivers](https://directorlink.io/drivers). Free. No subscription, no license key, no account with us.

DirectorLink is an independent project, not affiliated with Control4 or Snap One. Not affiliated with or endorsed by Samsung.

This beta passes its tests against recorded SmartThings answers from real Samsung washers, but it has not run on a
real washer yet. The first model to test is the WW90CGC04DAH (Series 5 ecobubble, 9 kg). If you try it, please send
the **Print Diagnostics** output (see *Testing the beta* in the README).

### In the Control4 app

- **Washer** tile: off, ready, running (water in the drum), paused, finished (green check) or error (red "!"), with
  text such as *Washing - Eco 40-60, 1 h 40 min left, done 14:32*.
- **A tap only reads the washer again.** It never pauses, starts or stops it.

### In Composer

- **Events:** Cycle Started, Cycle Paused, **Cycle Finished** (once per cycle: never repeated while the washer stays
  finished, nor after a controller restart; a cycle stopped before its end doesn't count), Error, Remote Control
  Enabled / Disabled, Command Failed, Authorization Required.
- **Variables:** STATE, JOB_STATE, PROGRAMME, REMAINING_MINUTES, FINISH_TIME, PROGRESS_PERCENT, SPIN, TEMPERATURE,
  KIDS_LOCK, REMOTE_CONTROL_ENABLED, LAST_FINISHED (ids 1001–1011, fixed from now on).
- **Conditionals:** State is Off / Ready / Running / Paused / Finished / Error; Remote Control is Enabled / Disabled.
- **Commands and actions:** Pause, Resume, Stop, Start, Refresh, and **Print Diagnostics**.

### Safe control

- Pause, Resume and Stop use SmartThings' `washerOperatingState.setMachineState`.
- **Start and Resume are sent only when the washer itself reports Smart Control on**, read just before sending.
  Otherwise *Start refused: Press Smart Control on the washer first*, and the driver never retries by itself.
- The programme, temperature and spin are never changed.

### Also

- Discovery lists only the account's washers. Capabilities your washer doesn't report, or disables, are left out.
- Programme names for Samsung's course codes (for example *Eco 40-60*); an unknown code shows as *Course 1C*.
- Reads every 30 seconds while the washer is on and every 2 minutes while it is off, within SmartThings' rate limits.
- The SmartThings sign-in is the same as DirectorLink · Samsung Refrigerator's: a Personal Access Token once, then
  the driver's own OAuth login, which it renews by itself. Tokens are never logged or shown.

### Files

`DirectorLink-Samsung-Washer.c4z`. Check it against `SHA256SUMS.txt`. Keep the file name exactly as it is: a browser's
`(1).c4z` copy installs as a separate driver.

### Installing

Upload the file with **Driver → Add or Update Driver or Agent**, search **DirectorLink**, add
**DirectorLink · Samsung Washer**, and follow the four setup steps on its Documentation tab.
Requirements: Control4 OS 3.3 or newer, Composer Pro, a Samsung washer on Wi-Fi in the SmartThings app.
Full steps: [directorlink.io/drivers/samsung-washer](https://directorlink.io/drivers/samsung-washer).

### Known issues

- **Not yet confirmed on a real washer** (the reason for the beta).
- **Errors:** no recorded washer has reported an error to SmartThings yet. The driver shows Error when the washer reports
  one in `samsungce.errorAndAlarmState` or `custom.error`; which washers do is one thing this beta should find out.
- **Some washer-dryers** disable remote control of the cycle in SmartThings: their state shows, but Pause, Resume, Stop
  and Start are refused with a clear reason.
- **Course names:** some course codes have no known name yet and show as *Course XX*.
