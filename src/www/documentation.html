Follow and control a Samsung Wi-Fi washing machine from Control4 through the Samsung SmartThings cloud: its state, programme, time left and finish time on a Washer tile, events for programming, and safe Pause, Resume, Stop and Start. The driver never changes the programme, temperature or spin.

Requirements

  • The washer is on Wi-Fi and added to the homeowner's SmartThings app.
  • The controller has internet access (HTTPS to api.smartthings.com).
  • About 10 minutes, a browser, and the login of the Samsung account the washer is registered to.

Setup

Step 1 - Create a SmartThings Personal Access Token

  1. On a computer, open https://account.smartthings.com/tokens.
  2. Sign in with the same Samsung account that the washer is registered to in the SmartThings app.
  3. Click Generate new token and give it any name, for example Control4.
  4. Under Authorized Scopes, tick every checkbox in these three sections: Devices, Locations, Apps. If in doubt, tick everything on the page. The token is used once and expires after 24 hours.
  5. Click Generate token and copy the value, which looks like 1a2b3c4d-1111-2222-3333-444455556666. It's shown only once.
  6. In Composer, paste it into the Personal Access Token property and click Set.
Common token mistakesWhat you see
No checkboxes tickedCreate app failed: Forbidden
Only Devices ticked (Apps missing)Create app failed: Forbidden ... needs ALL Apps scopes
Token older than 24 hoursCreate app failed: Not authorized. Create a new token.
Signed in with a different Samsung accountNo washers found

Step 2 - Create the OAuth app (this creates your Client ID)

On the Actions tab click 1. Create OAuth App (uses Personal Access Token). OAuth Client ID and OAuth Client Secret fill in by themselves, and Authorization Status says OAuth app created.

There is nothing to look up: the driver creates the Client ID for you. SmartThings never shows the secret again, so write both values down. If you add the driver again later, paste the same Client ID and Secret instead of creating a new app.

Step 3 - Authorize (sign in once)

  1. Click 2. Show Authorization URL. The link appears on the Lua tab (Lua Output) and in the Authorization URL property.
  2. Open it in a browser and sign in with the same Samsung account. Choose the location with the washer, then click Authorize.
  3. The browser goes to a page whose address starts with https://httpbin.org/get?code=. Copy the whole address from the address bar.
  4. Within a few minutes, paste it into the Authorization Code property and click Set. Codes expire; if it fails, open the link again. Pasted it into OAuth Redirect URI or Personal Access Token by mistake? The driver notices, puts that field back, and signs in anyway.

Authorization Status now reads Authorized (OAuth) ... renews automatically. From now on, the driver renews its access itself. The Personal Access Token isn't needed anymore.

Step 4 - Select the washer and show the tile

Discovery runs after authorization and lists only washers (not dryers, dishwashers or other devices). With one washer it is selected for you; otherwise choose it in Select Washer. Reported Features shows what the washer tells SmartThings.

The driver appears in the room as Washer. In Composer, open the room's Navigator settings and make the Washer tile visible on a menu.

A tap on the tile only reads the washer again and shows its state. It never pauses, starts or stops the washer. To pause or resume from a touchscreen, add programming on purpose (for example a custom button running Pause).

Safe control

  • Pause, Resume and Stop use SmartThings' washerOperatingState.setMachineState. Stop cancels the cycle.
  • Start and Resume set the drum moving, so they are sent only when the washer itself says remote control is enabled: someone pressed Smart Control on the washer. The driver reads the washer just before deciding. Otherwise the command is refused, Driver Status says Start refused: Press Smart Control on the washer first, Command Failed fires, and the driver never retries by itself.
  • Every command reads the washer first and is refused with a reason when it can't work (for example the washer is not running). After a command the driver re-reads the washer until it confirms, or fires Command Failed. A command is never re-sent.
  • The programme, temperature, spin and other settings are never changed.

Programming

TypeItems
CommandsStart (only with Smart Control on), Pause, Resume (only with Smart Control on), Stop (cancels the cycle), Refresh
EventsCycle Started (resuming is not a new cycle), Cycle Paused, Cycle Finished (once per cycle, never repeated while it stays finished or after a restart; a cycle stopped or cancelled before its end doesn't count), Error, Remote Control Enabled, Remote Control Disabled, Command Failed, Authorization Required
ConditionalsState is Off / Ready / Running / Paused / Finished / Error; Remote Control is Enabled / Disabled
Variables STATE (Off, Ready, Running, Paused, Finished, Error; empty before the first read), JOB_STATE (Washing, Rinsing, Spinning, ...; empty when no cycle runs), PROGRAMME (for example Eco 40-60), REMAINING_MINUTES (number), FINISH_TIME (local HH:MM), PROGRESS_PERCENT (number), SPIN (for example 1400 rpm), TEMPERATURE (for example 40 °C), KIDS_LOCK (bool), REMOTE_CONTROL_ENABLED (bool), LAST_FINISHED (ISO 8601 UTC, kept across restarts)

Finished lasts from the end of a cycle until someone switches the washer on again, or until Show Finished For has passed (default 120 minutes; 0 = until it's switched on again).

Examples

  • Laundry's done: on Cycle Finished, send a push notification or flash the hall lights.
  • Forgotten laundry: on Cycle Finished, start a 30-minute timer; if State is Finished when it ends, notify again.
  • Quiet hours: at 22:00, if State is Running, run Pause.

Each read is two requests, so the driver stays well inside SmartThings' limit of about 12 requests a minute per device. If SmartThings answers rate limited, polling pauses for two minutes. If the washer drops off Wi-Fi in the middle of a cycle, the cycle stays shown (offline, last known) instead of a new one being announced when it comes back.

Testing the beta

  1. Complete the setup and set Debug Mode to On.
  2. With the washer switched on, run Print Diagnostics (Actions tab) and copy the whole output from the Lua tab.
  3. Start a cycle at the washer, run Print Diagnostics again while it runs, and check that the tile, State, Programme, Time Remaining and Finish Time match the washer's display.
  4. If you can, press Smart Control on the washer and try Pause and Resume. Try Start once with Smart Control off: it must be refused.
  5. If the washer shows an error code while you test, run Print Diagnostics while it shows.
  6. Send the outputs, the washer's model number and your Control4 OS version from the page above.

Print Diagnostics never shows a token or secret, the washer's serial number or its full device id.

Troubleshooting

  • Start refused: Press Smart Control on the washer first: press Smart Control on the washer, then send Start again.
  • ... does not accept it through SmartThings: this model doesn't offer that control to SmartThings (some washer-dryers).
  • ... was not confirmed by the washer: SmartThings accepted the command but the washer didn't change. Check that it is online in the SmartThings app and that Smart Control is on.
  • Washer offline in SmartThings: some washers leave Wi-Fi when switched off; then State shows Off and this is normal.
  • Create app failed: see the token mistakes table in Step 1.
  • Authorization failed: the code expired or was already used. Open the link again and paste the new address quickly.
  • Re-authorization required: SmartThings rejected the saved token, for example after about 30 days with the controller offline, or after access was removed in the SmartThings app. Repeat Step 3. Steps 1-2 aren't needed.
  • Programme shows Course 1C: that course code's name isn't known yet. Send Print Diagnostics and the name on the dial.

Privacy and security

The driver talks only to the Samsung cloud. It sends nothing to DirectorLink and collects no usage data.

Tokens are kept in Control4's encrypted storage and are never written to the log or shown anywhere. The Client Secret is a masked property, but anyone with Composer access to the project can read it. To revoke access, remove DirectorLink Samsung Washer from the connected services in the SmartThings app, or click Sign Out (clear tokens).
